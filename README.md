# Mindbox ToDo Application

Простое и удобное ToDo-приложение, разработанное в рамках тестового задания для Mindbox.
https://mindbox-todo-pi.vercel.app/

## 🚀 Особенности

- Добавление задач
- Фильтрация задач: Все/Активные/Завершенные
- Удаление выполненных задач
- Сохранение данных в localStorage
- Адаптивный дизайн
- Полная типизация с TypeScript

## 🛠 Технологии

- Next.js
- React
- TypeScript
- Jest + Testing Library для тестирования

## 📦 Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AtyushevD/mindbox-todo.git
   ```
2. Установите зависимости:
    ```bash
    cd mindbox-todo
    npm install
    ```
3. Запустите приложение:
    ```bash
    npm run start
    ```
